FAQ

常见问题

需要提前安装 Java 吗？
不需要。CCL 会自动扫描本机已有的 JDK，检测不到合适版本时会从 Adoptium 自动下载托管，并根据游戏版本自动选择对应的 Java 主版本。
三种界面风格有什么区别？
只是界面不同，核心功能完全一致。PCL2 风格与 HMCL 风格版本包含最新的全部功能；原版风格是保留的初版布局，供对照与回退使用，日常建议选择前两者。
支持正版（微软）账户吗？
支持。CCL 实现了完整的微软设备码登录流程（Xbox Live → XSTS → Minecraft 令牌），令牌自动刷新；同时也提供离线模式。
我的游戏数据放在哪里？
默认位于系统 .minecraft 文件夹（与 PCL CE 相同的目录模型）：实例在 versions\实例名\，libraries 与 assets 全局共享，并自动生成 launcher_profiles.json。支持五档版本隔离，也可一键从旧版 CCL 目录迁移。
整合包和模组怎么装？
内置 Modrinth + CurseForge 双源模组市场，按当前实例的版本与加载器智能匹配、一键安装；整合包可直接导入 .mrpack 或 CurseForge manifest.json，游戏本体、加载器、模组与配置一次装齐，也支持导出分享。
