Features

从启动游戏到开房间，一条龙

XMCL 内核负责把游戏跑起来，CCL 负责把账号、联机和同步串起来。

CCL 账号

邮箱验证码即可注册，免记密码；支持设置密码、两步验证与恢复码，桌面和手机同一个账号。

账号就是游戏账号

内置 Yggdrasil 认证服务器，添加一次 zh.ccl.caiwenjun.top/api/yggdrasil，就能用 CCL 账号直接登录游戏。

Campfire 联机

P2P 打洞 + 中继兜底，不用公网 IP、不用端口映射，房主开好房间，朋友凭房间码进来。

CCL 房间大厅

开房后一键发布到大厅，房间码、版本、人数、模组一目了然，别人点一下就能加入。

LittleSkin 皮肤站

内置皮肤站登录，选好角色一键绑定；皮肤由 CCL 重新签名后发给游戏，正版服也能看到。

FAQ

常见问题

需要提前安装 Java 吗？
不需要。CCL 会扫描本机已有的 JDK，找不到合适版本时自动下载托管，并按 Minecraft 版本选择对应的 Java 主版本。
CCL 账号和微软账号冲突吗？
不冲突。两者是并列的登录方式，可以在启动器里同时存在、随时切换。CCL 账号适用于支持 authlib-injector 的服务器，微软正版账号用于正版验证服。
手机端和电脑端数据互通吗？
账号、角色绑定和云端设置（语言、主题、内存、操作偏好等）是互通的。游戏实例、存档与模组保存在各自设备本地，不会自动上传。
联机需要公网 IP 或端口映射吗？
不需要。Campfire 会优先尝试 P2P 打洞，失败时自动走中继；你只需要把局域网房间发布到 CCL 大厅，或把房间码发给朋友。
支持哪些皮肤站？
内置 LittleSkin 登录并支持一键绑定角色，也可以手动填写其他 Yggdrasil 皮肤站地址。绑定 LittleSkin 角色时，皮肤会由 CCL 重新签名后下发。
我的游戏文件放在哪？
桌面端默认使用系统 .minecraft 目录模型，实例在 versions\实例名\，libraries 与 assets 全局共享，支持多档版本隔离；也可以在设置里改到任意位置。
Linux 版怎么安装？
两种方式任选：AppImage 下载后 chmod +x ccl-2.1.0-x64.AppImage 直接运行，不需要安装；tar.xz 解压后运行目录内的 ccl。x64 与 arm64 都有对应文件，注意别下错架构。
旧版 1.0.0 还能下载吗？
能。旧版（Tauri 内核的 PCL2 / HMCL / 原版三种界面）仍保留在 Releases 页面，但已停止更新，建议使用 2.1.0。
